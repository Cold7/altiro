# Fonts used by the LaTeX manual

`ManualSerif-*.ttf` are static instances (weights 400 and 700, upright and
italic) generated with fontTools from the variable font **Lora**
(Copyright 2011 The Lora Project Authors, https://github.com/cyrealtype/Lora-Cyrillic).
XeLaTeX cannot embed variable fonts, so static instances were needed. Because
"Lora" is a Reserved Font Name under the SIL Open Font License 1.1, the
derived fonts are renamed **ManualSerif**. They are distributed under the same
license; see `OFL.txt`.

The manual also uses Inter (headings) and DejaVu Sans Mono (code), which must
be installed on the system.
